# Part 5 Sprint

TOEIC® L&R Part 5(短文穴埋め問題)の練習ゲームです。
ハイウェイを走りながら、空所に入る正しい単語に車をぶつけます。

**▶ プレイする: https://alomsoltanul.github.io/part5-sprint/**

## 遊び方

1. 画面の上に、空所のある英文が出ます。
2. 4つの選択肢の単語が、道路の前から1つずつ流れてきます。
3. 車を動かして、正しい単語にぶつかります。まちがった単語はよけます。
4. まちがえるとクラッシュして、ピットストップで日本語の解説が出ます。

| 操作 | キーボード | スマホ |
|---|---|---|
| ハンドル | ← → (A / D) | 道路をドラッグ、または「左」「右」ボタン |
| ニトロ(加速) | ↑ (W / Space) | NITRO ボタン |

早く正解するほど高得点です。連続で正解すると、コンボで最大 ×2.0 になります。

## レベルとオプション

- レベル: 600 基礎 / 730 中級 / 860+ 上級(各30問、合計90問)
- コース: ショート 10問 / フル 30問
- スピード: ゆっくり / ふつう / はやい
- 問題タイプ: すべて / 品詞 / 語彙 / 文法
- 車の色: 赤 / 青 / 黄 / 白
- ヒント: プレイ中に和訳を表示
- 効果音: オン / オフ

結果画面では、タイプ別の正答率と、まちがえた問題の復習ができます。

## 作り方

このゲームは Claude AI に3つのプロンプトを送って作りました。

1. ゲームの土台(画面、車の操作、単語の流れ方、点数のルール)
2. 問題データ(3レベル × 30問、日本語訳・解説・語彙つき)
3. 学習機能と仕上げ(ピットストップ、結果画面、復習、オプション、スマホ対応)

ファイルは `index.html` 1つだけです。インストールは必要ありません。
